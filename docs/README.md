# docs/

Engineering documentation that lives with the code: design notes, assessments,
and session records. The published, reader-facing documentation lives in
[`docs-site/`](../docs-site/) and is deployed to
<https://branes-ai.github.io/reflex/>.

Suggested layout as content lands:

- `arch/`: architecture and design decisions (controller interfaces, lifecycle, timing model)
- `assessments/`: analyses and trade studies (e.g. PID vs. MPC on a given airframe)
- `sessions/`: dated records of development sessions
