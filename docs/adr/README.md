# Architecture decision records

One file per load-bearing decision in reflex: what was decided, why, and what it commits us to. The format follows cortex's [`docs/adr/template.md`](https://github.com/branes-ai/cortex/blob/main/docs/adr/template.md): Status / Date / Related, Context, Decision, Consequences, and a closing *Current state* line. Files are numbered from 0001 and named after the decision: `0001-short-title.md`.

The decisions are published, with their status, on the [architecture site](https://branes-ai.github.io/architecture/reflex/), next to the other repos' decisions, rather than on reflex's own site.
