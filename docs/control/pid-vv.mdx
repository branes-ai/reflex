This plan takes [`Pid`](pid.mdx) to grade **A** under the
[building block standard](../standards/building-blocks.md). It lists where the
controller stands against each requirement, the animations that illustrate
its checks, the evidence ledger, and a sequence of PRs.

**Scope.** Pid is a discrete algorithm: its control law *is* its
specification, so there is no continuous model whose discretization it has
to converge to. Verification checks that it computes that law, holds its
invariants, and behaves as its contracts say in closed loop. Whether its
gains suit a vehicle is the business of the loops built from it, the
[cascade](cascade.mdx) above all, and their V&V.

**Consumers.** The cascade's rate loop (three Pids at 1 kHz, output in
rad/s²) and its velocity loop (three Pids, output in m/s²), in
racing-drone's B0 baseline.

### Closed-form offset (BB-V1)

A PD loop on $\ddot z = u + d$ settles where the P term holds up the
offset: $e = -d/K_p$, so $z = r + d/K_p$. The P-only loop oscillates about
the same point, undamped.

setpoint` holds a first-order plant at its actuator limit for 2 s and then
asks for a reachable setpoint. The scenario flies the same loop, beside a
copy whose limits are set wide open, so that its anti-windup never engages.

## Evidence ledger

| Claim | Evidence | Harness | Gate |
|---|---|---|---|
| Each term computes its part of the law | P, I, D, and filter cases with closed-form values | `tests/sdk/pid` | PR |
| The output and the integral stay within their limits | Saturation and clamp cases; I2–I4 asserted after every update | `tests/sdk/pid` | PR |
| Anti-windup freezes the integral only while it would wind up | Both directions, own and external saturation | `tests/sdk/pid`, `tests/sdk/cascade` | PR |
| A non-positive dt holds the output and state | Contract case; trace replay | `tests/sdk/pid`, `pid/timing_fault` | PR |
| Zero steady-state error and bounded overshoot in closed loop | First-order plant, double integrator with offset | `tests/sdk/pid_closed_loop` | PR |
| Recovery from saturation within 0.2 s, to within 0.02 | Closed-loop test; trace check | `tests/sdk/pid_closed_loop`, `pid/windup` | PR |
| Same law across scalar types | Closed loop within 1e-5 (32-bit types) and 1e-2 (`posit<16,1>`) of double | `tests/sdk/pid` | PR |
| The traces match the code | Regenerated and compared under `regen` | `Docs traces` CI job | PR |
| The live widgets run the same code | Wasm against native under `wasm`, at the defaults | `npm run wasm-agree` | PR |
| A fixed operation count per update | Counted-type test, per filter and primed state | `tests/sdk/pid_resource` | PR |
| Symmetry and scaling relations hold | Metamorphic tests (M2) | `tests/verification/pid_metamorphic` | PR |

The last row is planned.
