# Session logs

A log per working session: what was done, what was decided and why, what was left open, and where to pick up. They are working records, not documentation: docs-kit keeps this folder off the site (`unpublished: ['sessions']` in [`docs-site/docs-kit.config.mjs`](../../docs-site/docs-kit.config.mjs)).

Files are named by date and topic, `YYYY-MM-DD-short-topic.md`, so they sort in order. A decision that outlives the session goes in an [ADR](../adr/README.md), and a plan in [`plan/`](../plan/).
